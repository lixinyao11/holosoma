# Holosoma training package

This package contains the training implementation used by the two Isaac Sim
hybrid whole-body tasks in this release:

```text
exp:g1-29dof-wbt-hybrid-climb
exp:g1-29dof-wbt-hybrid-object
```

Use the repository [README](../../README.md) for installation, Stage 1 and
Stage 2 training, and Viser evaluation commands.

See the [hybrid WBT guide](../../docs/wbt-hybrid.md) for the track/gen design,
observations, reset and goal noise, rewards, curriculum, and termination
behavior.
